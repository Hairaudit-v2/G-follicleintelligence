## Executive verdict

Six curated FI OS screenshots are published as **faithful WebP derivatives** of the originals in `public/os Images/`. Website framing (border, radius, shadow, caption) is applied in CSS only.

## FI-WEB-REFRESH-1I-A correction

### Root cause

The initial FI-WEB-REFRESH-1I prepare script incorrectly treated demonstration clinic data as sensitive production data. It applied chrome redraws, SVG text overlays, mask bands, blur plates, and aggressive crops. Those edits must not ship.

### Clarification

The source screenshots were captured from the **FI Demonstration Clinic**. Visible names, clinic details, and patient information are **demonstration data**, not real patient or production records.

Therefore published assets must **preserve** demonstration identities and UI content exactly.

### Incorrect sanitisation removed

All six previously altered `public/os-images/fios-*.webp` files were deleted and regenerated **directly from the original JPEGs** (never from the edited WebPs).

| Altered behaviour removed |
|---|
| Red / dark masking bands |
| Artificial blur plates |
| “Patient A” / rewritten labels |
| Chrome redraw / clinic text replacement |
| Metric reframing on Surgery |
| Aggressive / asymmetric crops |

### Prepare script

`scripts/prepare-fios-marketing-screenshots.mjs` now performs **convert-only**:

- Input: original JPEG under `public/os Images/`
- Output: WebP quality **92**, `smartSubsample: false`
- Crop: **None**
- Resize: **None** (full 3314×1230 retained; no upscale)
- Content alterations: **None**
