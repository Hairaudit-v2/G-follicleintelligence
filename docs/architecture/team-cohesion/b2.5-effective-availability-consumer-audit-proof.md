## Delivered

### 1. Shared availability explanation

`StaffAvailabilityExplanation` on every `getStaffAvailabilityForRange` result:

- `available`, `source`, `reason`, `overrideType`, `blockingRecordId`, `effectiveStart` / `effectiveEnd`
- Sources: `weekly_hours` · `available_override` · leave / sick / maternity / unavailable / training / admin · `outside_weekly_hours`

### 2. Slot finder aligned with Bookings gate

`findNextAvailableBookingSlots` loads overlapping `fi_staff_availability_blocks` for the search horizon and filters via `isCandidateSlotWithinStaffEffectiveAvailability` → `getStaffAvailabilityForRange`.

- Leave / sick / unavailable **suppress suggestions**
- Same-day `available_override` **enables outside-hours suggestions**
- Weekly hours alone no longer authorise a live suggestion

### 3. Roster explanation UI

- Grid chips show block reason (+ override tone)
- Shift drawer shows `explainRosterDayAvailability` panel (`data-testid="roster-availability-explanation"`)
- CC payload includes `workingHoursByStaffId` + cell `reason`

### 4. Deduped generation blocking types

`rosterGenerationCore` imports canonical `BLOCKING_AVAILABILITY_BLOCK_TYPES` (no local duplicate Set literals).
